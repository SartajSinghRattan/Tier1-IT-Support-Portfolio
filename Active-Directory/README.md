# Active Directory

## Overview
This project documents the most common Active Directory tasks required in Tier 1 Help Desk, IT Support, Service Desk, and Desktop Support roles in Canada. It focuses on user account management, password resets, group membership, and clear communication.

## Skills Demonstrated
- Creating, unlocking, disabling, and managing user accounts
- Password resets with “must change at next logon”
- Adding and removing users from security groups
- Structured, repeatable processes
- Plain-language explanations for non-technical users
- Professional documentation style

## Files in This Project
- `AD-Common-Tasks.md` — Step-by-step technical procedures
- `Plain-Language-Explanations.md` — Clear, polite explanations for end users

## Interview Connection
This project prepares me to answer common questions such as:
- “How would you reset a user’s password?”
- “A user is locked out — what do you do?”
- “How do you handle adding someone to a group?”

It also shows that I can document processes clearly and communicate technical steps in plain language — reducing friction for both the user and the team.

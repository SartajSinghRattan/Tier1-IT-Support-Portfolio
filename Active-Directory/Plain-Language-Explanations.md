# Plain Language Explanations

These are examples of clear, polite explanations I would give to non-technical users.  
The goal is to reduce confusion and make the user feel supported.

## Password Reset
“I’ve reset your password. The next time you log in, you’ll be asked to create a new one. If you run into any trouble, just reply to this ticket and I’ll help you right away.”

## Account Unlocked
“Your account was locked, but I’ve unlocked it now. You should be able to log in normally. Let me know if you still see any error messages.”

## Added to a Group / Access Granted
“I’ve added your account to the group that gives you access to the shared folder. It can take a few minutes to take effect. Please try again and let me know if you still can’t open it.”

## New Account Created
“Your new account is ready. I’ll send you the temporary password separately. You’ll be asked to change it the first time you log in. Feel free to reach out if you need help getting started.”
